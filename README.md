# 디스코드 영어 → 한글 화면 번역기

Windows 10 22H2 이상에서 디스코드 데스크톱 앱의 원문 위치에 한국어 번역을 겹쳐 표시합니다. 번역 글자는 원래 디스코드 창 위에 나타납니다. 번역이 표시된 곳에서도 클릭과 스크롤을 할 수 있습니다. 봇, 서버 권한, API 키, 유료 구독이 필요 없습니다.

## 처음 한 번만 준비

1. [Ollama Windows판](https://ollama.com/download/windows)을 설치하고 실행합니다.
2. PowerShell에서 `ollama pull hf.co/tencent/HY-MT1.5-1.8B-GGUF:Q4_K_M`을 실행합니다. [HY-MT 1.8B 모델](https://huggingface.co/tencent/HY-MT1.5-1.8B-GGUF)은 약 1.1GB입니다. 경량 모델이 설치되어 있지 않거나 해당 원문 언어를 지원하지 않으면 기존 TranslateGemma 4B 모델을 사용합니다. 모델을 내려받은 후에는 오프라인에서도 번역할 수 있습니다.

## 사용 방법

1. Ollama를 실행한 상태에서 디스코드 채널을 엽니다.
2. `Start.cmd`를 더블 클릭합니다. 화면 상단 중앙에 열리는 설정 바에서 **원문 언어**를 고릅니다. 한국어 OCR만 설치된 PC에서도 **영어 (한국어 OCR로 읽기)**를 사용할 수 있습니다.
3. **채팅 영역 선택**을 눌러 디스코드의 메시지 부분을 드래그한 다음 **번역 시작**을 누릅니다.
4. **번역 중지**를 누르거나 설정 창을 닫으면 화면 위 번역이 사라집니다.

채팅 영역을 선택하면 설정 바가 해당 모니터의 상단 중앙으로 이동합니다. 필요하면 설정 바의 제목을 드래그해 옮길 수 있습니다. 채팅 화면은 초당 60프레임을 목표로 확인합니다. HY-MT는 새 줄을 최신순으로 한 줄씩 바로 표시하고, TranslateGemma는 최대 네 줄씩 번역합니다. 같은 원문을 다시 만나면 프로그램이 실행 중인 동안 문장과 화면 글자 모양을 비교해 번역을 재사용합니다. 묶음 응답의 줄 번호를 검증할 수 없으면 더 작은 묶음으로 다시 요청합니다. 스크롤할 때 화면에 남아 있는 글자 모양을 프레임마다 추적해 번역도 원문과 함께 이동합니다. 화면 밖으로 나가거나 현재 위치를 확인하기 어려운 줄은 표시를 중단합니다. 다시 나타난 줄은 OCR로 위치를 확인하고 기존 번역을 재사용합니다. 다른 창이 채팅을 가리면 번역을 숨깁니다. 디스코드 창을 옮기거나 크기를 바꾸면 영역을 다시 지정하세요.

화면 이미지는 파일로 저장하지 않습니다. OCR로 읽은 글은 이 PC의 Ollama에서 번역됩니다.

## 확인

```powershell
powershell.exe -NoProfile -STA -File .\Translator.ps1 -SelfTest
powershell.exe -NoProfile -STA -File .\Translator.ps1 -SmokeTest
powershell.exe -NoProfile -STA -File .\Translator.ps1 -LiveTest
```

처음 두 명령은 OCR, 번역 그리기, 설정 창 및 데스크톱 오버레이를 확인합니다. 마지막 명령은 Ollama에 두 모델이 설치되어 있을 때 실제 한국어 번역과 응답 시간을 비교합니다.
